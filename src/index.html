aqua-insight-voice

This project successfully integrates front-end development with a simulated AI backend to provide users with multi-faceted groundwater information. The core is an interactive chatbot, which supports both text and voice input (using the Web Speech API) in English and Hindi. Key capabilities include: Data Visualization: Generating dynamic charts and graphs to display historical and monthly water quality data, including levels, Total Dissolved Solids (TDS), and quality indices. Predictive Analytics: Displaying simulated 5-year predictions for groundwater levels to help users understand future resource availability. Location Comparison: Providing a clear, side-by-side comparison of multiple water metrics between different geographical areas using both bar and radar charts. User Experience: Implementing a sleek, water-themed design language using Tailwind CSS custom utilities and animations (like gradient-water and animate-float) to create a polished and intuitive user interface.

saathiya-mind-connect

Saathiya is an AI-driven mental wellness platform designed to support India’s youth through empathetic, confidential, and culturally-tuned conversations. Built with a chat-first interface, Saathiya offers micro-therapy sessions based on CBT and DBT principles, real-time crisis triage powered by AI, and gamified self-growth tools to promote emotional resilience. The system integrates AI fine-tuning for contextual empathy, a human-in-the-loop safety mechanism, and zero-knowledge encryption to ensure privacy and trust. It follows a B2B2C and freemium model—empowering schools, colleges, and workplaces to deploy accessible mental health support. Tech Stack: AI/ML: Gemini API, fine-tuned LLMs, vector databases (Pinecone/Milvus) Backend: Node.js/NestJS, Python/FastAPI, PostgreSQL, Redis Frontend: Next.js + React, Tailwind CSS, shadcn UI Real-time Systems: WebSockets, Socket.IO Infrastructure & Security: AWS/GCP, encryption vaults, audit logging

SCRUBX

PDF Redaction Roulette 🕵️‍♂️ is a secure web application that automatically detects and redacts sensitive personal information from PDF documents. Designed for privacy protection and hackathon-ready use, it ensures that no confidential data—like Aadhaar, PAN, emails, phone numbers, or credit card details—leaves the user’s system. All files are processed locally and deleted immediately after redaction for maximum security. Key Features: Automatic detection using advanced regex-based pattern matching Real-time redaction and instant download Clean, responsive, and modern UI Local-only file handling (no cloud storage) Extendable with OCR, encryption, and analytics modules Tech Stack: Frontend: React, Vite, TailwindCSS, JavaScript/JSX Backend: Flask, PyMuPDF (fitz), Flask-CORS, Regex Security: Local processing, input validation, CORS protection Deployment: Docker & Gunicorn-ready
